# Pranaya Wellness Sanctuary

An exquisite wellness and restorative spa sanctuary web application in Bhopal, Madhya Pradesh. Uniting therapeutic deep-tissue bodywork, calming hydro-thermal rituals, botanical skin therapies, and authentic Vedic healing in quiet, climate-controlled suites.

## Brand Identity & Meaning

- **Name**: **Pranaya Wellness Sanctuary** (Short: *Pranaya Wellness* / *Pranaya*).
  - *Etymology*: Derived from the ancient Sanskrit *Prāna* (the vital life-force and restorative breath of living energy) and *Ayana* (a haven, sacred repose, and gentle homecoming).
  - *Phonetics*: "Pruh-NAH-yuh" — 3 melodious, effortless syllables that are easily read, pronounced, and remembered worldwide.
  - *Context*: Perfectly reflects the serene lakeside ambiance of Bhopal ("City of Lakes") and authentic botanical, Ayurvedic, and musculoskeletal therapies.
- **Custom Logo Emblem**: An original vector insignia uniting the sacred *Prana* botanical lotus petal cradling a golden core seed and tranquil zen water arc, symbolizing restoration, purity, and life balance.
- **Refined Color Palette**: Warm Ivory (`#FAF7F2`), Soft Cream (`#F3EFE6`), Muted Eucalyptus Green (`#446353`), Warm Ochre/Gold (`#C89D66`), Soft Terracotta (`#B3644C`), Warm Taupe & Sand (`#ECE4D8`), and Deep Espresso Noir (`#201C17`).

## Features

- **Interactive Pages**:
  - **Home**: Sanctuary hero banner, 4-pillar trust strip, featured therapies with real-time category filter, guest reviews, and integrated Google Maps embed.
  - **About Us**: Ethos, principles of care, hygiene & suite privacy standards, and certified master practitioner credentials.
  - **Services & Pricing**: Full catalog with tariffs in INR (₹), treatment steps, durations, search, and etiquette FAQs.
  - **Sanctuary Gallery**: Visual tour of therapy spaces and botanicals with interactive lightbox zoom.
  - **Contact & Map**: Location overview, concierge contact form, operating hours, and interactive Google Maps embed.
- **Direct Code Download**: Built-in 1-click **Download ZIP** functionality that downloads `pranaya-wellness-project.zip`.
- **Live Admin Config Editor**: In-app drawer to customize office address, email, phone, and dynamic Google Maps coordinates in `src/config/business.ts`.
- **Custom Vector Logo & Favicon**: Scalable SVG logo component with responsive dark/light modes and SVG browser tab favicon.

## Run Locally

**Prerequisites:** Node.js (v18+)

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the local development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
