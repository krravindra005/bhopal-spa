# AuraNest Wellness Sanctuary

An exquisite wellness and restorative spa sanctuary web application in Bhopal, Madhya Pradesh. Uniting therapeutic deep-tissue bodywork, calming hydro-thermal rituals, botanical skin therapies, and authentic Vedic healing in quiet, climate-controlled suites.

## Features

- **Brand Identity**: AuraNest Wellness Sanctuary (Bhopal, Madhya Pradesh).
- **Unique Color Palette**: Warm Ivory (`#FAF7F2`), Soft Cream (`#F3EFE6`), Muted Eucalyptus Green (`#446353`), Soft Terracotta (`#B3644C`), Warm Taupe & Sand (`#ECE4D8`), and Deep Espresso Brown (`#28231D`).
- **Interactive Pages**:
  - **Home**: Sanctuary hero banner, 4-pillar trust strip, featured therapies with real-time filter, guest reviews, and integrated Google Maps embed.
  - **About Us**: Ethos, principles of care, hygiene & suite privacy standards, and certified master practitioner credentials.
  - **Services & Pricing**: Full catalog with tariffs in INR (₹), treatment steps, durations, search, and etiquette FAQs.
  - **Sanctuary Gallery**: Visual tour of therapy spaces and botanicals with lightbox zoom.
  - **Contact & Map**: Location overview, concierge contact form, operating hours, and interactive map embed.
- **Direct Code Download**: Built-in 1-click **Download ZIP** functionality that downloads `auranest-wellness-project.zip`.
- **Live Admin Config Editor**: Live in-app drawer to customize office address, email, phone, and dynamic Google Maps coordinates in `src/config/business.ts`.

## Tech Stack

- **React 19**
- **Vite 8**
- **TypeScript 7**
- **Tailwind CSS v4**
- **React Router v7**
- **Lucide React**

## Run Locally

**Prerequisites:** Node.js (v18+)

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the local development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
